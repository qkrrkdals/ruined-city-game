# 9시 47분 / 9:47 — 승인된 기획서 (A안 「등불의 열쇠」 확정본)

> 이 문서는 0단계에서 승인된 기획을 정리한 것이다. 구현 세부는 코드와 `CLAUDE.md`를 따른다.

## 1. 개요
- 1인칭 오픈월드 탐험 · 미스터리 · 가벼운 생존. PC 브라우저(키보드·마우스). 플레이 20~30분.
- 자연에 뒤덮인 폐허 도시 **청안시 / Clearhaven**. 로우폴리 파스텔, 플랫 셰이딩, 짙은 높이 안개.
- 언어: 한국어(기본) / English. 모든 문장은 `src/i18n/ko.json`, `en.json`.
- 핵심 경험: 낮 → 노을 → 밤 → 새벽으로 깊어지는 도시를 지나 늘 보이는 시계탑으로 간다. 손전등은 길을 보여 주지만 잔류체를 부른다.

## 3. 이야기 (A안)
- 주인공 **한유진**(이름은 후반에 드러남)은 아카이브를 만든 수석 연구원. 동생 **하람**은 진행성 기억 소실을 앓았다.
- 가동 기념식 날 밤 21:47, 유진은 하람의 기억을 지키려고 **안전 제한 해제**를 하고 아카이브를 최대로 돌렸다. 아카이브는 연결된(보존 등록된) 시민 모두의 기억을 한꺼번에 빨아들였다. → 시민은 기억 소실자가 되어 구조되었고, 도시는 봉쇄되어 숲에 묻혔다. 모든 시계가 9시 47분에 멈췄다.
- **잔류체** = 주인을 잃고 새어 나온 기억. 빛과 소리를 따라오고, 닿으면 머릿속으로 밀려든다(= 잡히면 암전).
- 아카이브는 다가오는 사람의 기억을 강제로 빼앗고 쓰러뜨린다. 그래서 아무도 탑에 오르지 못했다. 혼자 남은 유진은 **자기 기억을 미리 아카이브에 맡겨 텅 빈 사람이 되기로** 했고, 텅 빈 자신이 길을 잃지 않도록 쪽지·쉼터의 램프·배터리를 도시 곳곳에 남겼다. → 쪽지가 내 필체이고, 쉼터와 배터리가 늘 그 자리에 있는 이유.
- 1인칭에서 "사진 속의 나"는 **노란 카디건**(`#E8B73F`)으로 보여 준다. 물건을 들면 1인칭 팔의 노란 소매가 보이고, 사진·광고판 속 사람도 같은 옷.
- **엔딩**: 새벽, 탑 꼭대기에서 중앙 제어 장치에 21:47을 입력 → 10년 만에 시곗바늘이 움직이고 종이 울린다 → 잔류체가 기억 조각으로 풀려 하늘로 떠올라 도시 밖 주인들에게로 흩어진다 → 마지막 빛 하나가 돌아와 유진의 기억이 돌아온다(기념식의 음악, 하람의 웃음, 레버를 당기던 손) → 일지 마지막 줄 "내 이름은 한유진. 이제 하람을 찾으러 간다." → 해 뜨는 초록 도시를 내려다보며 크레딧.

## 7. 생존 규칙
- 손전등: 가득 차면 연속 3분. 배터리 +35%(가득 차면 줍지 않음). 15% 아래 깜빡임, 0%면 빠르게 깜빡이다 꺼짐. 맵 배터리 14개 + 쉼터 5곳의 다시 채워지는 배터리.
- 잔류체: 배회 → 의심 → (1초 예고) → 추적 → 놓침 → 복귀. 손전등 켜면 시야 25m, 끄면 7m/앉으면 3m. 소리: 달리기 15m, 걷기 7m, 앉아 걷기 2m, 착지 10m, 던진 병 18m. 추적 속도 < 달리기 속도. 쉼터 램프 빛 안으로 못 들어옴.
- 잡히면 암전 → 마지막 쉼터. 쪽지·퍼즐 진행 유지, 들고 있던 물건은 원래 자리로, 배터리 최소 30%.
- 등장 구간: 주차장 1(튜토리얼, 느림) · 상업 지구 밤거리 2 · 쇼핑몰 1 · 지하상가 3 · 터널 1 · 광장 2 · 연구소 2 · 탑 16층 1.
