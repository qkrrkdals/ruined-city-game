# 9시 47분 · 9:47

> 내가 잊은 기억 — The Memory I Forgot

자연에 뒤덮인 폐허 도시 **청안시**에서 기억을 잃은 채 깨어납니다.
낮에서 노을, 밤, 새벽으로 깊어지는 도시를 지나 언제나 보이는 시계탑으로 향하세요.
손전등은 길을 보여 주지만, 빛을 따라오는 **잔류체**도 부릅니다.

로우폴리 파스텔 그래픽의 1인칭 탐험 · 미스터리 게임입니다. 엔딩까지 20~30분이 걸립니다.

## ▶ 플레이
**https://qkrrkdals.github.io/ruined-city-game/**

PC 브라우저(키보드·마우스) 전용입니다. 헤드폰을 쓰면 더 좋아요.

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 마우스 | 이동 / 시점 |
| Shift | 달리기 |
| Space | 점프 |
| C | 앉기 · 숨기 |
| E | 상호작용 (줍기, 읽기, 들기·내려놓기) |
| F | 손전등 |
| J | 일지 |
| P | 일시정지 (Esc를 누르면 자동으로 일시정지, 클릭하면 계속) |

## 만든 방법
- Three.js + Vite. 3D 모델·텍스처·음원 파일 없이 모두 코드로 생성했습니다.
- 한국어 / English 지원.

---

You wake up with no memory in Clearhaven, a ruined city swallowed by green. Head for the clock tower as afternoon turns to night and night to dawn. Your flashlight shows the way, but it also draws the Remnants. A first-person low-poly pastel exploration-mystery game for desktop browsers (20–30 minutes). Korean and English supported.
