# 마르지 않는 병풍 — 제1폭 「까치와 범」 기획서

3D 로우폴리 수묵 액션 RPG. PC 브라우저(키보드·마우스), 한국어, 1장 데모(약 60분).

## 1. 한 줄 소개
화공이 그리다 만 여덟 폭 병풍. 낙관이 찍히지 않아 **먹이 마르지 않고 번지는** 그림 속에서,
윤곽만 그려진 채 잊힌 **밑그림**이 화공이 떨어뜨린 **몽당붓**을 들고 번짐을 "맺어" 나간다.

## 2. 세계관
- 세계는 병풍 그림 속. 그려진 것들이 살아간다. 그림은 **낙관**이 찍혀야 끝나고, 끝나야 먹이 마른다.
- 화공은 여덟째 폭 앞에서 붓을 놓고 사라졌다. 마르지 않은 먹이 번져(**번짐**) 그려진 것들을 삼킨다.
- 화공의 문방사우가 그림 속에서는 신화적 지형이다: 붓(무기), 먹(검은 비석), 벼루(보스의 못), 연적(쉼터).
- 번짐이 닿은 곳은 색을 잃어 먹빛만 남는다. 연적의 맑은 물을 깨우면 **담채(색)** 가 번져 돌아온다.
- 서양 판타지가 아니라 **수묵화·민화**: 호작도(까치와 범), 장승, 솟대, 사군자, 영자팔법.

## 3. 인물
- **밑그림**(주인공): 삿갓 쓴 나그네의 밑그림. 얼굴이 그려지지 않았다. 말이 없다. 덧칠할수록 먹빛이 짙어진다.
- **소식**(까치): 좋은 소식을 물어 오는 길잡이. 수다스럽다. 범 "얼룩"의 오랜 짝.
- **얼룩 / 먹범**(보스): 호작도의 범, 붓골의 수호 범. 마을로 오는 번짐을 혼자 받아 내다 먹범이 되었다.
- 붓골 사람들: **배첩 영감**(표구장, 붓 손질), **먹 할멈**(도장·이슬 가게), **서안 선비**(낱장 부탁), **물이**(연적지기 아이), **장승 둘**(먹문 문지기).
- **화공**: 등장하지 않음. 곳곳의 쪽글(화제)로만 흔적이 남는다.

## 4. 전투 (손맛 우선)
- 3인칭 실시간. 약공격 4연타(좌클릭), 강공격(우클릭, 누르고 있으면 모아 치기), 연계(약→강, 약약→강, 약약약→강).
- **획**(먹을 쓰는 기술): Q 점찍기(돌진 찌르기) · F 삐침(날아가는 먹 칼날) · C 파임(뛰어올라 내려찍기).
- **여백**(Space 회피): 종잇장처럼 얇아져 스친다. 아슬아슬하게 피하면 세상이 잠깐 백지로 멈추고 다음 일격이 강해진다.
- **흐트러짐 → 맺음**: 적의 흐트러짐 게이지를 채우면 무너진다. E로 **맺음** — 붉은 낙관이 찍히는 마무리.
- 먹 게이지: 때리면 차고, 획에 쓴다. 호리병(R)으로 회복. 조준 고정(T/휠 클릭).
- 타격감 장치: 히트스톱, 카메라 흔들림·킥, 먹 튐·종이 조각, 먹 얼룩, 붓자국 궤적, 연타 음계(가야금 뜯는 소리), 슬로 모션.
- 적은 공격 전에 붉은 기미(예고)를 보인다. 동시에 덤비는 수는 제한(공격 순번제).

## 5. 성장
- **먹물**(적 처치·항아리) → 연적에서 **덧칠**: 기운(체력) / 필력(공격) / 먹심(먹 획득·칸). 농담 단계: 담묵→중묵→농묵→초묵.
- **획** 3종: 점찍기(초반), 삐침(묵장 처치), 파임(먹두꺼비 처치).
- **붓 손질**(배첩 영감, 붓털 필요) · **호리병 이슬**(회복 횟수) · **도장** 6종 중 2개 장착(송·죽·매·난·국·학).
- 죽으면 마지막 연적에서 다시 시작(잃는 것 없음, 적은 다시 번짐). 연적에서 자동 저장.

## 6. 지도 (병풍 한 폭 = 세로로 긴 그림. 아래가 가깝고 위가 멀다)
```
            [벼루못]  보스: 먹범
               |
            벼룻길 (연적)
               |
 [묵장의 터]  먹문·장승  [먹두꺼비 연못]
     |         |            |
   대숲 ---- 붓골(마을) ---- 갈대늪
  (연적)    (큰 연적)       (연적)
               |
            솔숲 길
               |
          첫 연적 · 여백(시작)
```
- 흐름: 여백(조작 익히기) → 솔숲(첫 싸움, 맺음) → 붓골(거점) → 대숲·갈대늪(순서 자유, 각 중간 보스 → 획 획득, 지름길 열림) → 먹문 → 벼룻길 → 벼루못 → 결말.
- 곁길: 궤(도장·붓털·이슬·먹물), 화공의 쪽글 8, 법첩 낱장 3.

## 7. 적
| 이름 | 특징 |
|---|---|
| 먹물이 | 작은 먹 방울. 떼로 덤빈다 |
| 번진 군졸(창) | 찌르기·후리기 |
| 번진 군졸(방패) | 정면 약공격을 막는다 → 강공격·획·뒤 |
| 번진 학 | 먹을 뱉고 내리꽂는다 |
| 먹멧돼지 | 일직선 돌진. 피하면 빈틈 |
| 탈 쓴 군졸 | 정예. 3연격 |
| 묵장(중간 보스) | 월도. 넓은 후리기·늦은 내려치기 |
| 먹두꺼비(중간 보스) | 뛰어 덮치기(충격 고리)·혀·먹 뱉기 |
| 먹범(보스) | 2단계. 앞발·덮치기·꼬리·포효 / 줄무늬 칼날·먹 잠수 |

## 8. 아트·소리
- **수묵 로우폴리**: 한지색 바탕, 먹 농담, 붉은 인주·쪽빛·금박만 포인트. 그림자 없음(수묵화), 먼 곳은 여백으로 사라짐.
- 후처리: 깊이 기반 먹선(윤곽), 한지 결, 번짐 비네트. 연적을 깨우면 그 둘레로 담채가 번져 나간다.
- 모든 모델·질감·소리는 코드로 생성. 글꼴: 동해독도·연성·송명(OFL), 쓰는 글자만 잘라 넣음.
- 소리: Web Audio 합성. 가야금(뜯는 줄), 대금, 북·장구·징·목탁. 탐험은 느린 산조풍, 전투는 자진모리, 보스는 휘모리.

## 9. 조작
WASD 이동 · 마우스 시점 · 좌클릭 약공격 · 우클릭 강공격(모으기) · Space 여백(회피) · Shift 달리기 ·
E 말 걸기/맺음 · R 호리병 · Q/F/C 획 · T(휠 클릭) 조준 고정 · M 지도 · Esc 멈춤. (Ctrl·Tab 사용 안 함)

## 10. 결말(제1폭)
먹범을 맺으면 첫째 폭 전체에 색이 돌아오고, 범 얼룩이 제 모습을 찾는다. 까치와 범이 소나무 아래 다시 만나고(호작도),
밑그림은 병풍의 접힌 틈 너머 둘째 폭으로 향한다. "제2폭에서 계속."
